## 域名匹配变化

HAR 210 终于包含原小说网页，实际域名为 `m.diyibanzhu.me`。旧版只处理 `m.03banzhu.com`，所以新域名的 HTML 清理和推广导航来源判断没有执行。抓包里的旧横幅已是透明图片，说明部分精确资源规则已经生效，不能把剩余广告全部归因于用户没有更新。

按用户要求改为：

- 网页脚本只在 URL 的主机名含 `banzhu` 时匹配，支持不同域名后缀和端口；查询参数或路径里出现该词不会匹配。
- MitM 使用 `*banzhu*`，依据 [Loon 官方通配符说明](https://nsloon.app/docs/MitM/)。
- 已知推广请求的 Referer/Origin 也按主机名含 `banzhu` 判断；完整推广目标、端口和路径仍严格限定。

没有添加 `DOMAIN-KEYWORD,banzhu,REJECT`，因此不会拒绝小说站本身。该方式也会覆盖其他主机名包含此关键字的站点；广告处理仍只针对已确认资源和节点。不含这个词的新站点域名不会自动覆盖，推广目标/广告文件自身轮换也仍可能需要更新。
